# Sensor Readings Analysis

Analysis of wall-following robot sensor data using Python and Pandas.

## Project Overview

This project analyzes sensor readings collected from a wall-following robot dataset using Pandas.

The analysis focuses on inspecting the dataset, understanding its structure, checking data quality, and analyzing sensor features and movement classes.

## Dataset

The dataset contains:

* 5,455 records
* 24 sensor features
* Movement class information

## Analysis Performed

* Data inspection
* Missing-value checks
* Data-type analysis
* Descriptive statistics
* Sorting and filtering
* Grouping
* Duplicate checks
* Movement class analysis
* Separation of sensor features and movement target

## Technologies Used

* Python
* Pandas
* Jupyter Notebook

## Key Concepts

* DataFrame operations
* Data inspection
* Data cleaning checks
* Filtering and sorting
* Grouping
* Indexing
* Feature and target separation

## Project File

`Sensor-Readings-Analysis.ipynb`

The Jupyter Notebook contains the complete analysis and implementation.

## Learning Objective

This project was created to practice Pandas and apply data-analysis techniques to a robotics-related sensor dataset.
